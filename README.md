# kakao-analytics — 내 대화 기록도 한곳에, 내 맥 안에서만

맥용 카카오톡이 이미 제 기기에 저장해 둔 제 대화 기록을 그 기기 안에서만 읽어, 한곳에 모으고 통계·검색을 무인으로 만드는 개인 도구입니다.

> 코드는 공개하지 않습니다. 이 저장소는 판단과 제약만 적은 README입니다. 대화 기록과 결과는 기기 밖으로 나가지 않고, 이 문서에도 들어 있지 않습니다.

| 항목 | 내용 |
|:--|:--|
| 기간 | 2026.08 ~ 진행 중 (첫 판 2026-08-26, 최근 변경 2026-09-29, 커밋 19개) |
| 역할 | 개인 프로젝트 — 설계·구현·운영 (사용자 1인, 본인 기기 1대) |
| 스택 | Python 3 표준 라이브러리, launchd, 구독형 Claude Code CLI(요약만) |
| 상태 | 운영 중 — launchd 에이전트 2개 |

## 맥락

흩어진 제 데이터 중 가장 큰 갈래는 대화 기록입니다. [허브](https://github.com/WJY-ador/consultant-side-lab)에서 말한 "모으기"를 이 갈래에도 하려고 만들었습니다.

지금 되는 것은 모으기·통계·검색까지입니다. 그 너머의 방향은 나중에 에이전트가 제 말투와 응답 방식대로 답장을 돕는 것입니다. 이 방향은 아직 만들지 않았습니다.

카톡 대화는 서버가 내려 주지 않고 앱이 도는 기기에만 저장돼 있습니다. 그래서 대화를 데이터로 쓰려면 그 기기 안에서 읽어야 합니다.

## 제약

제가 먼저 건 제약 다섯 개입니다. 설계는 이 안에서만 했습니다.

- **완전 무인.** 수동 내보내기나 파일 드롭도 거부합니다.
- **맥 상시 구동 불필요.** 맥이 깨어 있고 잠금이 풀린 시점에만 돕니다.
- **시스템 보안 설정 유지.** 업무 데이터가 있는 기기라 OS 보안 기능을 끄는 방법은 쓰지 않습니다.
- **로컬 전용·무료.** 외부 전송 0, 종량제 API 0.
- **요약은 무인이 아닙니다.** 무인은 수집·통계·검색까지입니다. 아래 「무인 요약 예외」가 유일한 예외입니다.

## 흐름

1. **트리거** — launchd 에이전트 하나는 카톡의 로컬 저장 파일이 바뀌면 2~6을, 다른 하나는 하루 세 번(09:40·13:00·17:30) 2~7을 돌립니다.
2. **가드** — 카톡이 실행 중이고 화면 잠금이 풀려 있을 때만 진행합니다. 120초 안에 다시 불리면 건너뛰고, 잠금 파일로 중복 실행을 막습니다.
3. **사본 읽기** — 앱 파일은 건드리지 않고 로컬 저장 기록의 사본을 만들어, 그 사본을 기기 안에서 읽습니다.
4. **누적** — 읽은 기록을 로컬 누적 저장소에 upsert합니다. 이전 사본과 비교해 신규·수정·삭제를 가립니다.
5. **통계** — 방별 대화량과 월별 추이를 계산합니다. 본문은 읽지 않고 메타만 씁니다.
6. **대시보드** — 외부 리소스 없는 단일 HTML을 로컬에 다시 만듭니다. 집계만 넣고 본문은 넣지 않습니다.
7. **요약(정해진 시각 실행만)** — 제가 고른 화이트리스트 방의 새 대화만 구독 CLI로 배치 요약합니다.

## 단계별 판단

**① 화면 자동화를 버렸습니다.** 처음에는 앱 화면을 읽는 쪽을 봤습니다. 판단: 카톡 맥 앱은 메시지 행이 접근성 트리에 텍스트를 노출하지 않고, 내보내기 버튼에도 라벨이 없었습니다. 좌표 클릭은 깨지기 쉽고 화면을 점유합니다. 남은 무인·무음 경로는 앱이 기기에 저장해 둔 기록을 읽는 것뿐이었습니다.

**② 마크다운에 바로 덧붙이지 않습니다.** 판단: 다시 읽을 때마다 같은 대화가 또 들어오고, 수정·삭제된 메시지가 섞입니다. 누적 저장소를 기준으로 두고 .md는 거기서 다시 만듭니다. 카톡이 로컬에서 오래된 메시지를 정리해도 저장소에는 남습니다. 앱의 정리와 실제 삭제는 방별 현재 최소 시각으로 구분합니다.

**③ 통계는 본문을 읽지 않습니다.** 대화량·추이는 메타만으로 나옵니다. 대시보드도 본문을 싣지 않습니다.

**④ 큰 방은 요약을 세 갈래로 나눕니다(2026-09-07).** 100명 넘는 방은 한 줄 요약이 의미가 없었습니다. 제 관심 축에 걸린 것, 반응이 많은 주제, 링크·영상으로 나눕니다. 오픈채팅 방장의 300자 넘는 글은 반응과 무관하게 전문으로 따로 싣습니다(2026-09-10).

## 무인 요약 예외

「요약은 무인이 아니다」의 좁은 예외를 2026-08-26에 제가 승인했습니다. 안전장치는 세 개입니다.

- 대상은 제가 고른 화이트리스트 방뿐입니다.
- 모델 출력은 JSON 스키마 검증을 통과한 방만 씁니다. 실패한 방은 읽음 위치를 올리지 않아 다음 회차에 다시 시도합니다.
- 무인 생성분에는 `ai_auto=True`, `reviewed=False`를 붙이고 대시보드에 "AI 무검토"로 표시합니다. 세션에서 제가 손본 요약은 `reviewed=True`로 두고, 무인 실행은 그 뒤 새 대화가 생긴 방만 다시 요약합니다.

## 되는 정도·한계

- **본인 기기 한 대, 이 앱 버전에서만 확인했습니다.** 다른 기기·다른 계정·앱 업데이트 뒤에는 확인하지 않았습니다.
- **무인 실행에는 파이썬에 전체 디스크 접근 권한이 필요합니다.** 없으면 조용히 건너뜁니다. 확인은 로그의 "run 완료" 줄로 합니다.
- **무인 요약은 검토 전 상태로 나갑니다.** "AI 무검토" 표시가 붙은 요약을 제가 다 읽는다는 보장은 없습니다.
- **답장을 돕는 에이전트는 아직 없습니다.** 지금 있는 것은 모으기·통계·검색·요약입니다.
- **결과는 로컬·본인용입니다.** 발행하지 않습니다.
- 맥이 잠들어 있거나 카톡이 꺼져 있으면 돌지 않습니다.

## 이 문서에 없는 것

- 코드, 로컬 기록을 읽는 절차의 세부, 참고 자료.
- 방 이름, 대화 내용, 요약 결과, 통계 값, 대화 규모.
- 이 도구는 제 기기에 저장된 제 기록을 읽는 용도입니다. 다른 사람의 기기나 계정에 쓰는 방법은 다루지 않습니다.
